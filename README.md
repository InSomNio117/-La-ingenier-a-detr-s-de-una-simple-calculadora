# -La-ingenier-a-detr-s-de-una-simple-calculadora
Calculadora de expresiones algebraicas basada en Árboles de Análisis y evaluación recursiva de nodos. Desarrollada en Java y C#. Proyecto académico.

 Objetivos del Proyecto

Prueba en Java (Consola):** Validación del funcionamiento del árbol sintáctico mediante la resolución lógica de expresiones algebraicas paso a paso desde consola.
* **Versión en C# (Consola):** Réplica de la lógica de nodos y evaluación recursiva implementada en entorno de consola para .NET / C#.
* **Interfaz Gráfica de Usuario (GUI - Java Swing):** Aplicación de escritorio interactiva donde el usuario puede ingresar cualquier expresión algebraica válida desde el teclado y calcular el resultado de forma dinámica mediante un botón.

---

## 🛠️ Tecnologías y Entornos Utilizados

* **Lenguajes:** Java, C#
* **Entornos de Desarrollo (IDE):** Apache NetBeans, Visual Studio / Visual Studio Code
* **Librerías GUI:** Java Swing (`javax.swing`)
